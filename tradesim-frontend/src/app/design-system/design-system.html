<!-- Pass an ISO string -->
<span>{{ '2024-05-10T12:00:00Z' | timeAgo }}</span>

Time Ago Usage timeAgo

Input Type Output Type Description
string | Date | number | null string Calculates the difference between the provided time and exactly now. Handles plurals automatically and returns "Just now" for times under 30 seconds or invalid inputs.
