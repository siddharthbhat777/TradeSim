Properties & Slots

Property / Slot Type Default Description
text string '' The simple string text to display inside the tooltip panel.
position 'top' | 'right' | 'bottom' | 'left' 'top' The preferred popover position relative to the anchor. Falls back automatically if space is restricted.
<ng-content> (Default) Slot - The element that acts as the trigger (anchor) for the tooltip.
