Properties

Property Type Default Description
variant 'primary' | 'secondary' | 'success' | 'danger' | 'warning' | 'outline' 'primary' The visual style of the button.
size 'small' | 'medium' | 'large' 'medium' Adjusts padding and font-size.
iconPosition 'left' | 'right' 'left' Determines if the icon projects to the left or right of the text.
isLoading boolean false Shows the inline loader and disables user interactions.
disabled boolean false Disables the button native functionality and applies opacity.
buttonClick EventEmitter<MouseEvent> - Emitted when clicked (safely ignores clicks if disabled or loading).
